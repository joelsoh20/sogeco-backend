Voici la marche à suivre pour créer les identifiants OAuth2 Google, adaptée à ta config actuelle (server.port=8080, context-path=/, registration google) :

1. Créer un projet (si tu n'en as pas déjà un)
Va sur console.cloud.google.com
En haut, clique sur le sélecteur de projet → Nouveau projet
Nomme-le par ex. sogeco-fleet-manager → Créer
2. Configurer l'écran de consentement OAuth
Menu ☰ → APIs et services → Écran de consentement OAuth
Type d'utilisateur : Externe (sauf si tu as un Google Workspace et veux restreindre à sogeco.cm, auquel cas Interne)
Renseigne le nom de l'app, l'email de support, l'email développeur
Scopes : ajoute openid, .../auth/userinfo.email, .../auth/userinfo.profile (ça correspond à scope: openid, profile, email dans ton application.yml)
En mode test, ajoute ton propre compte Google comme utilisateur de test
3. Créer les identifiants (Client ID)
Menu ☰ → APIs et services → Identifiants

Créer des identifiants → ID client OAuth

Type d'application : Application Web

Nom : sogeco-fleet-manager-dev (ou ce que tu veux)

Origines JavaScript autorisées :

http://localhost:8080
http://localhost:5173 (ton frontend, vu cors.allowed-origins)
URI de redirection autorisés — c'est le point important : Spring Security utilise par défaut


http://localhost:8080/login/oauth2/code/google
(calculé à partir de {baseUrl}/login/oauth2/code/{registrationId}, avec registrationId=google). Ajoute exactement cette URL.

Clique Créer → une popup affiche ton Client ID et ton Client Secret

4. Les renseigner dans le projet
Dans ton .env :


GOOGLE_CLIENT_ID=<le client id copié>
GOOGLE_CLIENT_SECRET=<le client secret copié>
